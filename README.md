# EcoCampus（碳足跡計算器 + 減碳模擬器）

## 執行方式

### 方法 A（推薦）VSCode + Live Server
1. 用 VSCode 打開此資料夾
2. 安裝外掛 **Live Server**
3. 右鍵 `index.html` → **Open with Live Server**

### 方法 B（直接開檔）
直接雙擊 `index.html` 也能跑（但圖示/圖表用 CDN，需要網路）。

## 功能
- 總覽儀表板：最近 7 天趨勢、類別分佈、今日/本週統計
- AI 行為推估：輸入一句話自動解析並新增紀錄（含抽菸/放屁/煙霧彈）
- 行為紀錄：新增/刪除、篩選、匯入/匯出 JSON
- 減碳模擬器：
  - 減少紅肉用餐次數
  - 冷氣改用電瓶（可調低碳係數）
  - 改搭大眾運輸工具
  - 立即算出每週/每年減碳量
- 碳排資料庫：可調整排放係數（會影響計算結果）

## 備註
- 所有資料存在瀏覽器 localStorage；清除瀏覽資料會消失。
- 預設排放係數為示意值，可在「碳排資料庫」頁調整為你們報告引用數據。
